NEBULA CHAT — локальный сайт общения
Нужен Node.js 18+ (https://nodejs.org/). npm-пакеты не нужны.
1. Распакуй архив.
2. Открой терминал в папке nebula-chat.
3. Запусти: node server.js
4. Открой: http://127.0.0.1:3000

Есть регистрация, вход, общий чат и сохранение сообщений.
data/db.json создаётся автоматически. Пароли НЕ сохраняются открытым текстом: хранятся только соль и scrypt-хеш.
Сессии находятся в памяти и сбрасываются при перезапуске сервера.
Это демонстрационный проект для локального запуска. Перед публикацией в интернете необходимы HTTPS, усиление защиты от перебора/спама, резервные копии и аудит безопасности.
